# Deep Learning ANN Projects 🚀

This project demonstrates the implementation of Artificial Neural Networks (ANN) for both **Regression** and **Classification** tasks. The main focus of this project is to understand hidden layers, improve model accuracy, and evaluate performance using confusion matrix and other metrics.

---

## 📌 Project Overview

In this project, I have implemented ANN models from scratch and using deep learning libraries. The project explores how hidden layers work and how they impact model performance.

The primary goal is:
- To build efficient ANN models
- To improve prediction accuracy
- To analyze performance using evaluation metrics

---

## 📊 Datasets Used

1. **Regression Dataset**
   - Power Plant Dataset
   - Used to predict continuous output values

2. **Classification Dataset**
   - Date Fruit Dataset
   - Used for classifying different categories
